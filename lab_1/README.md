# Лабораторная работа 1: Анализ данных в задачах компьютерного зрения

Целью данной лабораторной работы является освоение базовых инструментов для работы с данными: NumPy, Pandas и Matplotlib в контексте задач компьютерного зрения (Computer Vision).

## Содержание

1.  **NumPy**: Манипуляции с тензорами (изображениями), векторные операции (без циклов).
2.  **Pandas**: Анализ метаданных набора изображений (загрузка, фильтрация, агрегация).
3.  **Matplotlib и визуализация**: Загрузка, отображение изображений, работа с каналами и гистограммами яркости.
